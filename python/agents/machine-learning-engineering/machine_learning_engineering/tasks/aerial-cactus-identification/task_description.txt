# Task

Predict whether an aerial image contains a columnar cactus (has_cactus). This is a binary classification problem. Images are 32x32 pixels stored in train/ and test/ directories.

# Metric

roc_auc

# Submission Format
```
id,has_cactus
000940378805c44108d287872b2f04ce.jpg,0.5
0017242f54ececa4512b4d7937d1e21e.jpg,0.5
etc.
```

# Dataset

train.csv
```
id,has_cactus
0004be2cfeaba1c0361d39e2b000257b.jpg,1
000c8a36845c0208e833c79c1bffedd1.jpg,1
000d1e9a533f62e55c289303b072733d.jpg,1
etc.
```

train/ (directory of 32x32 .jpg images, filenames match train.csv id column)
test/ (directory of 32x32 .jpg images, filenames to predict)
