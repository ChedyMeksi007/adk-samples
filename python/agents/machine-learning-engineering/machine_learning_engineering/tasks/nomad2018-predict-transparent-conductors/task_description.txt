# Task

Predict two target properties of transparent conductors: formation_energy_ev_natom and bandgap_energy_ev. This is a multi-output regression problem.

# Metric

root_mean_squared_log_error (RMSLE, mean across both targets)

# Submission Format
```
id,formation_energy_ev_natom,bandgap_energy_ev
1,0.1779,1.8892
2,0.1779,1.8892
etc.
```
