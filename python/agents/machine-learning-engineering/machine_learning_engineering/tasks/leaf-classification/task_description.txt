# Task

Predict the species of a leaf from pre-extracted features. This is a multi-class classification problem with 99 species. Each leaf has 192 features: 64 margin, 64 shape, and 64 texture descriptors. Predict the probability of each species. Images are also available in the images/ directory.

# Metric

multi-class log_loss

# Submission Format
```
id,Acer_Capillipes,Acer_Circinatum,Acer_Mono,Acer_Opalus,...,Zelkova_Serrata
4,0.010101,0.010101,0.010101,0.010101,...,0.010101
7,0.010101,0.010101,0.010101,0.010101,...,0.010101
etc.
```

One column per species (99 species total), values are predicted probabilities.
